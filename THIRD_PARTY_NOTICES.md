# Third-party notices

This repository does not vendor or compile third-party geometry libraries.

`RotateUV_AutoSeam.exe` is built from the C++ source in `src/autoseam_worker.cpp` using the C++ standard library.

The MAXScript uses functionality provided by Autodesk 3ds Max at runtime, including Unwrap UVW and native Unfold3D APIs. Autodesk software is not included in this repository.
